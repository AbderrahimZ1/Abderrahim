# azermane.com

Professional research portfolio for Dr Abderrahim Zermane.

## Free hosting

This is a static website designed for GitHub Pages. It has no paid server, database, or build dependency.

## Publish on GitHub Pages

1. Make this repository public.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Keep the `CNAME` file in the repository.
6. At the domain registrar, add the GitHub Pages DNS records documented by GitHub.

## Update content

- Main content: `index.html`
- Visual design: `styles.css` and `styles-1.css` to `styles-4.css`
- Interactions: `script.js`
- Portrait and CV: `assets/`

## Paper images

The first version uses original web graphics rather than publisher screenshots. Add author-owned or permitted paper images to `assets/papers/` and replace the research-card graphics when cleared for web use.
